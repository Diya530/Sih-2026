# 🚨 ResQ Helm — Smart Safety Helmet for Disaster Response

**🌐 Live Demo:** https://sih-2026-six.vercel.app/

## 📌 Overview

**ResQ Helm** is a smart safety helmet designed to improve the safety, monitoring, and communication of workers operating in hazardous and disaster-prone environments.

The system combines **real-time environmental sensing, worker health monitoring, emergency alerts, and intelligent data visualization** into a single connected helmet platform.

The project focuses on helping rescue teams, industrial workers, and disaster-response personnel stay safer while enabling supervisors to monitor critical conditions remotely.

## 🎯 Problem

Workers involved in construction, mining, firefighting, disaster response, and other hazardous operations can face sudden environmental dangers and health emergencies.

Traditional safety helmets mainly provide physical protection but offer limited capabilities for:

* Monitoring environmental conditions
* Tracking worker vital parameters
* Detecting dangerous situations
* Sending emergency alerts
* Providing real-time information to supervisors

**ResQ Helm** aims to address these limitations through a connected smart-helmet ecosystem.

## 💡 Key Features

### 🪖 Smart Helmet

A helmet-mounted sensing unit designed to continuously monitor important worker and environmental parameters.

### 🌡️ Environmental Monitoring

The system is designed to monitor hazardous environmental conditions such as:

* Temperature
* Humidity
* Harmful gases
* Air quality
* Other environmental parameters

### ❤️ Worker Vital Monitoring

The helmet can integrate sensors for monitoring worker health and activity, helping identify potentially dangerous situations.

### 🚨 Emergency Detection

The system is designed to identify abnormal or dangerous conditions and trigger alerts when immediate attention is required.

### 📡 Real-Time Monitoring

Sensor information can be visualized through a centralized dashboard, allowing supervisors or response teams to monitor workers remotely.

### 🗺️ Worker Tracking

The platform can support location-aware monitoring to help identify the position of workers during emergency situations.

### 📊 Monitoring Dashboard

The web interface provides a centralized view of the ResQ Helm system, its technologies, use cases, and monitoring capabilities.
